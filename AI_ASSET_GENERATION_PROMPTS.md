## 使用方法

このドキュメントには、Dungeon Stackのアセットを生成するためのAIプロンプトが含まれています。

### 推奨ツール
- **Midjourney v6**: 最高品質（月額$30）
- **DALL-E 3**: 良品質（ChatGPT Plus: 月額$20）
- **Leonardo.ai**: 無料枠あり

```
共通スタイル指示:
- 3D rendered game icon
- Clean white background
- Soft shadows and highlights
- Warm lighting
- Mobile game asset style
- High quality, professional
- 256x256 pixels minimum
```

## 6. 実践的なワークフロー

### Midjourney使用時

1. **Discordでプロンプト投稿**
   ```
   /imagine prompt: [上記のプロンプトをコピペ]
   ```

2. **4つの候補から選択**
   - `U1`, `U2`, `U3`, `U4`でアップスケール
   - `V1`, `V2`, `V3`, `V4`でバリエーション生成

3. **微調整**
   - `Vary (Strong)` で大きく変更
   - `Vary (Subtle)` で微調整
   - `Zoom Out` で構図変更

4. **ダウンロード**
   - アップスケール後の画像を保存
   - PNG形式で保存（透明背景が必要な場合は後処理）

---

### 背景透過処理

生成した画像の背景を透明にする方法：

#### オンラインツール
1. **remove.bg** (https://www.remove.bg/)
   - 無料で高品質な背景除去
   - アップロードするだけ

2. **Photoshop / GIMP**
   - マジック消しゴムツール使用
   - より細かい調整が可能

## 8. 最適化

### 画像サイズ推奨

| 種類 | 推奨サイズ | フォーマット |
|-----|----------|------------|
| アイテムアイコン | 256x256px | PNG (透過) |
| 敵キャラクター | 256x256px | PNG (透過) |
| プレイヤー | 128x128px | PNG (透過) |
| UIエレメント | 512x512px | PNG (透過) |
| エフェクト | 1024x256px | PNG (透過) |

### 圧縮ツール

- **TinyPNG** (https://tinypng.com/)
  - 品質を保ちながらファイルサイズを50-70%削減
  - 一括処理可能
