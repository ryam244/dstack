## 📝 実践的な生成手順

### ステップ1: Midjourneyアカウント準備

1. **Discord登録** (https://discord.com/)
2. **Midjourney参加** (https://www.midjourney.com/)
3. **サブスクリプション契約**
   - Basic Plan: $10/月（200枚/月）
   - Standard Plan: $30/月（無制限Fast mode）← 推奨

### ステップ2: Discordで生成

```
1. Discordを開く
2. Midjourney Botのいるチャンネルに移動
3. メッセージ欄に以下を入力:

/imagine prompt: [上記のプロンプトをコピペ]

4. Enterキーを押す
5. 約1分待つ
```

### ステップ3: 候補から選択

4つの画像（Grid）が表示されます：

```
[ 1 ]  [ 2 ]
[ 3 ]  [ 4 ]

操作ボタン:
U1, U2, U3, U4 → その画像を高解像度化（Upscale）
V1, V2, V3, V4 → その画像のバリエーション生成
🔄 → 全て再生成
```

**推奨操作**:
- 気に入った画像の `U` ボタンを押す（例: `U2`）
- 高解像度版が生成されるまで待つ（30秒程度）

### ステップ4: 背景透過処理

1. **画像をダウンロード**
   - 右クリック → 「画像を保存」

2. **remove.bg で背景除去**
   - https://www.remove.bg/ にアクセス
   - 画像をアップロード
   - 自動で背景が透明になる
   - 「Download」をクリック

3. **TinyPNG で圧縮**（オプション）
   - https://tinypng.com/ にアクセス
   - 透過PNG画像をアップロード
   - 圧縮後の画像をダウンロード

### ステップ5: ファイル名を変更して保存

```bash
# ダウンロードした画像のファイル名を変更
元: midjourney_image_12345.png
↓
新: sword.png

# 適切なフォルダに移動（Phase 0実装後）
→ DungeonStack/assets/items/sword.png
```

## 💡 Tips & Tricks

### 良い結果が出ない場合

1. **プロンプトに追加**:
   ```
   , highly detailed, 4k resolution, trending on artstation
   ```

2. **スタイルを統一**:
   - 全てのプロンプトに共通の文言を追加
   ```
   , consistent art style, same artist style
   ```

3. **色味を調整**:
   ```
   , vibrant colors (鮮やか)
   , muted colors (落ち着いた)
   , pastel colors (パステル)
   ```

### 複数アセットを効率的に生成

1. **まとめて生成**
   - 似たアイテムを連続で生成
   - 例: 剣 → 盾 → 薬 → 金貨

2. **バリエーション活用**
   - 1つ良いのができたら `V` ボタンで類似品生成

3. **イメージプロンプト併用**
   - 添付画像を参考にする場合:
   ```
   /imagine prompt: [画像URL] 3D rendered sword icon...
   ```
